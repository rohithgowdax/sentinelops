## 3. Paired Statistical Methodology

### Investigation Comparisons (McNemar's Exact Test)
Because each mode is evaluated against the exact same incidents, observations are naturally paired.
For two modes $M_1$ and $M_2$:
- $n_{11}$: Both correct
- $n_{10}$: $M_1$ correct, $M_2$ incorrect
- $n_{01}$: $M_2$ correct, $M_1$ incorrect
- $n_{00}$: Both incorrect

Null hypothesis $H_0: p_1 = p_2$.
The discordant count follows $n_{10} \sim \text{Binomial}(n=n_{10}+n_{01}, p=0.5)$. The exact two-sided p-value is:
$$p = 2 \times \sum_{k=0}^{\min(n_{10}, n_{01})} \binom{n_{10} + n_{01}}{k} 0.5^{n_{10} + n_{01}}$$
The paired difference in proportions is $\Delta = \frac{n_{10} - n_{01}}{N}$, with standard error:
$$\text{SE}(\Delta) = \frac{\sqrt{(n_{10} + n_{01}) - (n_{10} - n_{01})^2 / N}}{N}$$

### Retrieval Paired Bootstrap
For query-level metrics across identical queries, we draw $B=2000$ bootstrap resamples with replacement of query indices using a fixed random seed (`seed=42`). For each bootstrap sample $b$, we compute the mean difference $\bar{d}^*_b = \frac{1}{Q} \sum_{q} (M_{1, q}^* - M_{2, q}^*)$. The empirical 2.5% and 97.5% percentiles form the 95% bootstrap confidence interval.

## 6. Claim-Level Grounding Methodology

### Atomic Claim Decomposition
Agent diagnoses are parsed into atomic factual and causal claims:
- **Factual Claims:** e.g., `"Observed elevated memory utilization on order-service"`
- **Causal Claims:** e.g., `"Memory leak caused frequent GC pauses that stalled Kafka consumer commits"` (detected via causal connectives: *caused*, *leading to*, *due to*, *because*, *resulted in*).

### Protocol & Evaluator Architecture
- `ClaimGroundingEvaluator`: Protocol accepting `(claim, evidence) -> GroundingResult`.
- `HeuristicClaimGroundingEvaluator`:
  - Validates citation IDs against collected evidence.
  - Computes keyword/entity overlap against cited chunk content.
  - Checks for contradictory directional indicators.
  - Evaluates causal claims (requires multiple temporal/event evidence points).
- `ExternalJudgeClaimGroundingEvaluator`: Configured structure for cloud LLM judges.

### Decoupling of Grounding Dimensions
- **Citation Reference Validity:** Are cited evidence IDs valid and present in collected evidence?
- **Structural Evidence Support:** Does cited text contain relevant tokens and directional consistency?
- **Sentence-Level Semantic NLI Entailment:** Marked as **NOT EVALUATED** (no NLI cross-encoder model deployed).

## 8. Limitations

1. **Sentence-Level Semantic NLI Entailment is Unmeasured:** While 100% of cited evidence IDs exist and have positive token overlap, true natural language entailment (whether premise implies hypothesis) requires an NLI model.
2. **Offline Semantic Emulator Ceiling on Benchmark v2:** The current offline semantic emulator cannot perform multi-hop causal reasoning required for Benchmark v2. Testing with frontier LLMs (e.g. Claude 3.5 Sonnet, GPT-4o) requires external API credentials and network egress.
3. **Retrieval Paired Bootstrap Power:** On 50 queries, while `hybrid_plus_rerank` achieves the highest Recall@5 (0.7900), the bootstrap confidence intervals for retrieval differences span zero, meaning larger query sets (e.g., $N=500$) are needed to prove statistical significance in IR metrics.
